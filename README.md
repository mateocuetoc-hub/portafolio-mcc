# Portafolio MCC

Sitio web frontend para presentar una selección de proyectos digitales desarrollados por MCC.

## Ver el sitio

[Visitar Portafolio MCC](https://portafolio-mcc.chagptgrupo.chatgpt.site)

## Sobre el proyecto

El portafolio reúne proyectos web, backend, hardware y experiencias interactivas en una sola página responsiva. Incluye proyectos destacados, enlaces directos a sus repositorios y una presentación profesional.

### Proyectos destacados

- **La Misión Agua Purificada** — landing page para una pyme de San Felipe.
- **BeaGi Moda Circular** — catálogo y experiencia web para moda circular.
- **SonicFonoKids** — experiencia interactiva de apoyo fonoaudiológico infantil.

## Tecnologías

- React
- Next.js
- TypeScript
- CSS
- Vite / vinext
- Cloudflare Workers

## Ejecutar localmente

Requiere Node.js 22.13 o superior.

```bash
npm ci
npm run dev
```

## Validar una versión de producción

```bash
npm run build
npm test
```
