# Portafolio MCC

Portafolio frontend de Mateo Cueto para presentar proyectos de desarrollo web, software y automatización.

## Diseño

- Estética minimalista y luminosa
- Galería animada de proyectos
- Tarjetas responsivas con enlaces a GitHub
- Navegación flotante con efecto de vidrio
- Adaptado para escritorio y móvil

## Tecnologías

- Next.js
- React
- TypeScript
- CSS

## Desarrollo local

```bash
npm install
npm run dev
```

Luego abre `http://localhost:5173`.

## Publicación

El portafolio se publica automáticamente en GitHub Pages cada vez que se
actualiza la rama `main`:

https://mateocuetoc-hub.github.io/portafolio-mcc/

Para comprobar localmente la versión estática que utiliza GitHub Pages:

```bash
npm run build:pages
```
